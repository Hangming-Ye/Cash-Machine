# 投研框架 Intent

2026-09-20｜本轮intent对齐结果｜可据此进入spec，尚未确认具体实现方案

## 目标

构建供用户实际投资研究使用的完整框架。它应持续推进研究、提供有依据的判断并积累经验，解决现有Bot缺乏工作方法、主动规划不足、分析浅和难以参考的问题。

三类核心能力均在目标范围内：

1. **供应链探索**：类似Serenity的方法，从产业变化拆解需求、瓶颈和潜在受益公司，支持提前发现机会，并继续验证商业兑现、估值与反证。
2. **单票因子研究**：挖掘和验证对单只股票交易判断有帮助的因素，为用户的主观交易提供数据支撑；当前不以纯量化自动交易为目标。
3. **持仓与自选判断**：综合价格走势、市场情绪、行业与公司研究等，提供买入、卖出、观望的研究评价及有依据的理想价格或条件。

三类能力共同需要：深入数据分析、客观和主观信息源、历史判断回顾、经验沉淀，以及真正能持续完成工作的流程。投行研报、新闻与社交观点不能被基础行情接口替代。

## 使用方式与范围

- 以Grok Bot的常驻、定时、多Agent并发和手机访问形态为主要使用场景。
- 支持美股、港股、A股，不预设某市场永久优先。具体市场、赛道、标的、研究期限及关注范围由实际调用指定，不要求设计阶段确定首批赛道或固定名单。
- 用户给出目标和范围后，框架应能自主展开问题、发现新主题/公司、补证并推进到候选结论；重要的目标取舍再交用户决定。
- 供应链探索的调用范围不自动限制其他持仓分析或因子研究任务。
- 当前定位为投资研究与人工决策支持，订单执行不纳入本轮目标。

## 完整性与主动性

- 框架设计须充分覆盖三大目标内的合理研究需求，不能仅提供角色名称、取数接口或若干狭窄示例，再把常见问题作为“待扩展能力”退回用户。
- 市面上的skill、agent、MCP、CLI等都是调研对象；需要提取实际金融工作方法、能力和适用边界，而不只罗列工具。
- 专员应获得足以完成任务的岗位指令、研究方法、输入和交付要求，不能依赖父会话隐含背景或让模型自行猜测职责。
- 研究中应自主调整计划和补充证据。数据接口不可用或覆盖不足时，应主动尝试Web Search、原始披露等替代获取途径，继续推进可完成的部分，而不机械停在“数据源未接入”。
- 替代获取仍须保留来源、时间与局限，不能编造不存在的数据，也不能把零散搜索信息等同于已具备完整历史数据。确实无法获得的证据应明确说明，对受影响结论作限制。
- 研究没有发现合格机会、没有稳定因子增量，可以是有效结果；框架缺少本应覆盖的研究方法，不应被包装成正常完成。

## 复杂度与实现取舍

- 考虑用户当前主要使用Grok 4.5/4.6的实际体验，不能把可靠完成任务寄托于模型自由规划、临场协商或自行猜测方法。
- 整体保持简单；复杂且需要确定性的执行交给程序，模型承担适合其能力的材料理解和研究判断。岗位方法应清晰，但不因此限制用户自由提出目标内的问题。
- 旧sec-analysis仅提供部分数据拉取能力，可参考其接口经验。原代码复用优先级低；允许新建、局部复用或低成本改造，不为兼容旧工程改变目标和架构。

## 进入spec的边界

**当前intent已足够进入spec。** spec需要把上述目标落实为用户场景、功能边界、异常与替代路径、可检验的完成标准。可运行性和研究实用性都重要，不能仅以接口可调用或报告已生成为完成。

此前文档中的岗位数量、任务模板数量、技术栈、数据结构、流程节点、重试/补证上限和实现顺序均是设计候选，不视为用户已确认的intent。若某项设计限制了上述目标，应调整设计，不倒过来收窄目标。

本轮不继续询问具体投资赛道、个股或交易参数，不将这些运行时选择作为进入spec的前置条件；本文件也不表示已有设计、真实部署或模型效果通过验收。

## Spec001 反馈补充（2026-09-20）

- 券商只读接入是本轮要求：用户确认已有能力，凭证已提供。实际读取范围与联通在实现时核验，不再按“尚未接入、先手填”规划。
- 手机与 PC 混合使用，不影响交付格式；通知不在本轮设计范围。
- Grok Bot 已在 7×24 运行。依托已有常驻、定时及并发能力，聚焦研究方法接入；不额外构建复杂协议、状态机或恢复平台，调用失败可说明原因并简单重跑。
- 记忆必须形成复盘、经验提炼、去重压缩、相关检索、再注入及更新失效的完整过程。先调研现有方案，不能以保存历史记录代替可用记忆。

- 记忆设计必须结合定时、长期与重分析的任务特点，覆盖每次调用的增量、跨周期研究延续、深度分析依据的保留与复用；不能只套用通用聊天记忆方案。
- Plan 阶段数据候选沿用当前 Grok Bot 已有接入；发现遗漏单独登记，不重新做供应商选型。Plan 的新增假设与技术选择完成后交用户审批，再进入后续实现。
