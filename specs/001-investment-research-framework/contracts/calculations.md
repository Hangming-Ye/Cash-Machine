# 计算契约（P-05、P-06，拟实现）

程序只计算已声明的输入与方法，不生成投资决策，不接受任意 Python／SQL／shell 代码。以下操作集合是本轮已批准的初版覆盖，尚未实现；不是把研究问题限定为固定因子名。

## 因子表达

表达为 JSON 节点 `{op, args, params}`。叶节点为已验证数据列或数值常量；所有操作有明确参数类型、输入单位和缺失处理。示例为结构说明，不是可直接运行的完整实验请求：

```json
{"op":"subtract","args":[{"op":"safe_divide","args":[{"op":"field","params":{"name":"adjusted_close"}},{"op":"rolling_mean","args":[{"op":"field","params":{"name":"adjusted_close"}}],"params":{"window":20}}]},{"op":"constant","params":{"value":1}}]}
```

这表示相对均线距离，新窗口或合法组合不需要新增代码。参数组合由明确列表提供；不允许模型任意执行表达式字符串。

| 运算族 | 初版能力 | 校验 |
| --- | --- | --- |
| 输入 | field、constant；基准序列作为命名输入 | 列必须来自当前数据快照，有时点及口径；常量标单位 |
| 基础 | add、subtract、multiply、safe_divide、abs、sign、log、clip | 单位兼容；除零／log 非正值为缺失并警告；不输出无限值 |
| 条件组合 | gt、gte、lt、lte、and、or、where、weighted_sum | 条件取同一可得时点的值；不提供循环、外部函数或任意变量访问 |
| 时序 | lag、delta、pct_return、log_return | 向后操作，lag 不得为负；结果可用时间取所有依赖最晚时间 |
| 滚动 | sum、mean、median、min、max、std、quantile、rank、corr、cov | 作为 rolling_* 命名操作；窗口只向后、不居中；min_periods、方差自由度和缺失行为显式 |
| 衰减 | ewm_mean、ewm_std | span／alpha、adjust、ignore_na 明确，不由库默认隐含改变 |
| 历史对齐 | asof_value、event_age | 只连接当时已经可知的值；无合格历史则拒绝验证，不生成虚假 PIT |

z-score、波动率、量能异常、动量、回撤、位置及复合阈值等由以上操作组合；必要的便捷名称展开为同一表达，不增加执行权限。未来新增原语需开发，但现有操作的组合与参数在任务中完成，不再要求每个公式预先人工注册。

每个输入保留观测时间和 available_at；日期只证明顺序，不证明数据在当时实际存在。没有可靠历史版本时不得通过 asof_value 假装重建。新闻／财报提取的事件表必须保留原文与发布／可得时间，缺时间的搜索片段只能辅助提出假设。

输入参数个数、表达深度、单批组合量、内存和耗时采用运行配置限制；执行前显示预计组合数和数据覆盖，超限可拆成批次但仍计入同一试验集合。具体默认值通过样例测量后在实现配置记录，不作为用户研究范围上限。无未经登记的全排列自动搜索。

## 实验请求与验证

必需字段：hypothesis、failure_regimes、dataset_ref、expression、parameter_sets、target、horizon、bar_interval、baseline、available_time_rule、split、primary_metric、costs、trial_group。先完整保存冻结请求，FactorExperiment 记录 request_ref 与 request_hash，再执行；horizon、parameter_sets、primary_metric 等字段不得在持久化时丢失。metrics 为输出而非 primary_metric 的替代；请求变更形成新版本与试验 ID。

- 时间粒度作为实验参数（P-05），首个验证样例采用日频；同一引擎按有证据的数据粒度计算。非日频数据须通过同样的可得时间、间隔对齐、交易时段和覆盖检查，所需字段缺失时报告数据缺口，不能把日频当研究范围上限。收盘生成的信号不能用于当日收盘已发生的交易，最早使用时点依数据和市场交易规则确定。若不能支持交易模拟，可报告下一期收益分布等研究统计，但明确不是可执行收益。
- 按时间切分探索／验证／最终留出，训练标签覆盖到验证区间的样本剔除。窗口、目标期限、分割日期和成本按任务声明，不固定成一套适用于所有股票的年数。
- 标准化、缺失处理及选参数只在训练部分拟合；验证结果不反馈选同一轮参数。最终留出被查看后即不能继续称其未见；后续须标探索性结果或使用新时间段。
- 基准可为同标的无因子条件分布、简单持有或适用指数；明确比較含义和时点。对单票不用横截面 IC 作为默认效度结论。
- 输出覆盖／缺失率、样本数与重叠情况、样本外效果、跨时段稳定性、基准差、成本影响及失败情形。需要区间估计时采用保留序列依赖的 block resampling，块长由目标与数据协议声明；不把相邻天当独立样本。
- 没有可用基准、复权或可得时间时限制相应验证结论。程序缺原语与数据源缺信息必须分别报告。

每一个可被比较择优的公式、参数、期限、阈值或预处理变体均计试验；失败／弃用也保留。相同输入与配置的重放记 replay_of；纯基础设施重试不重复算新候选，但已见局部结果后的调整仍计新试验。报告 trial 数不自动等于完成多重检验校正；统计结论必须说明采用的比较方式与探索性限制。

## 估值请求

输入包括 method、valuation_date、currency、financial_refs、assumptions、scenarios、share_basis、net_debt、quote_ref（需当前价比较时）。所有模型假设由研究员提出并附理由；程序验证数值及口径、计算情景和敏感性。

| 方法 | 必要边界 |
| --- | --- |
| DCF | 预测现金流定义一致，折现率／终值假设明确；永续增长必须低于适用折现率；FCFF 与 FCFE 的桥接不同 |
| 可比倍数 | 估值指标与倍数分母一致，同行选取有业务依据；负分母或不可比项排除并说明 |
| EV→权益桥 | 净债务、少数股东等调整按实际口径声明；股本为同一时点的适用摊薄口径 |
| 分部／资产法 | 每个分部方法和币种明确，避免重复计算共同资产／债务；不把缺失分部补成零 |

结果给 bear／base／bull 情景、主要敏感性、模型警告与可复查输入。概率未有依据时不强制赋概率；模型算得出不意味着假设已证明。输入不足可交研究条件和里程碑，不能为了买入价编造数字。

## 计算验证

固定小表手算对照；截断未来数据不改变历史因子；训练／验证标签无重叠；复权事件、零除、缺失、同名证券、单位／币种不符、盘后发布、数据修订均有边界样例。同一输入／版本计算在声明精度内一致。上述是实施验证要求，本轮未运行数值引擎。
