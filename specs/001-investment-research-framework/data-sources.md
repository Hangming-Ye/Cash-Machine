# 现有数据基线与单列缺口

本 plan 按用户最新指令沿用现有 Grok Bot 接入，不重新选供应商。依据：[handoff](../../HANDOFF_FOR_SENIOR_PLANNER_20260920.md)、[原实现审阅](../../research/13-current-data-implementation.md)、[Intent](../../docs/intent.md)。用户已确认券商只读能力及凭证；在 T002 前的基线整理阶段未读取秘密内容、未调用账户或金融服务，T002 随后通过显式受保护配置执行本地只读 live 调用，当前事实见下文。

## 基线

| 来源 | 当前用途 | 规划处理及已知边界 |
| --- | --- | --- |
| Finnhub | US/HK 报价、公司／市场新闻 | 保留；不根据产品目录推定 candle、目标价或研报权限 |

网页搜索、公司 IR、交易所／监管披露和用户材料是现有 Bot 补证渠道，不是本轮新增供应商。金融 MCP 未列为已接入能力；不得把研究里出现过的商业服务默认为已购买。

## 缺口与处理

| ID | 遗漏／不确定项 | 当前方案 | 对验收的影响 |
| --- | --- | --- | --- |
| G-01 | 已取得 00700 连续历史日线导出，但 PIT／公司行动证明不足 | 原始／qfq 序列可保留来源后导入；不新增行情供应商 | 港股因子完整案例仍受阻，其他逐案研究可继续 |
| G-02 | Tiingo 调整／分红／拆分字段及 AKShare qfq 已见，但独立公司行动依据不足 | 保留原始值、调整字段和导出哈希；披露补公司行动 | 无法确定跨期可比性时，受影响收益与因子不作验证结论 |
| G-03 | FMP 三表可读，但 PIT、披露／修订链仍缺失 | 保存现有字段及原公告版本；不能用当前值冒充历史原值 | 基本面因子只能保留假设／描述性结果 |
| G-04 | 公开 IR／研究页可检索，研报全文及社交观点仍无系统化接入 | 逐案搜索公开材料并注明范围、保留反方材料 | 可支持具体研究，不宣称完整研报库／社交历史 |
| G-05 | 长桥直连账户／持仓读取成功，SDK 未见自选方法；项目适配器仍缺账户引用 | 自选允许用户提供；继续补项目适配器配置验证 | 自选未验证与持仓 live 成功分开记录，完整组合案例仍受限 |
| G-06 | 部分成功／错误已持久化；若干 available_at、时区、单位和覆盖事实仍未知 | 契约逐项保留未知与错误，不造日期或补零 | 关键字段质量不通过时受影响部分受限 |
| G-07 | 本轮未证明共享 cache 或并发配额保障 | 按请求处理供应商限额并报告限流 | 原生并发验收仍阻塞，不建中央调度器 |
| G-08 | 当前分析师预期可读；历史一致预期及结构化产业链量价／客户关系仍未确认 | 公开披露与研报补具体证据、标注估算，不自动采购 | 不伪称完整历史横截面或供应链数据库 |

缺口本身不删除功能需求。数据确实无法获得时可交受限研究，但不得把它计入 spec 的完整案例；最终验收未满足即明确保留未完成项，不能为“通过”改标。

## 每次调用的最小证据

来源结果保存：操作、实际来源、对象、观察时点、获取时点、口径、覆盖、数据文件与错误说明。缺口保存：所缺内容、影响的结论／实验、尝试过的既有源和网页路径、结果及下一动作。它们是事实记录，不需要审批流或缺口状态机。

底层结果区分成功、部分成功和失败；空数据、未授权、不支持、限流、过期、冲突分别给原因。历史缺口不会因为下一次成功自动消失，也不会覆盖当时判断。

持仓与账户数据只放私有运行目录；凭证沿用受保护环境配置或显式秘密文件，不写入请求 JSON、报告、共享模板或 Git。`sec-analysis.env` 的存在不作为新程序自动加载它的理由。

前置检查须先回答三市场完整案例是否有合格数据路径。公开资料或既有导出导入只是补证渠道，不预设能找到完整序列。若 G-01 等无法补齐，明确受阻的成功标准并单独报用户；继续独立工作，但不冻结一份声称全部验收可达的计划，也不擅自扩供应商。数据受阻不等于框架方法可以省略。
